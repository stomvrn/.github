# Как помочь

Спасибо за интерес к экосистеме.

## Что можно предложить

- Исправление ошибок в алгоритмах или текстах
- Уточнение формулировок (особенно медицинских)
- Дополнение примерами из практики
- Замечания по интерфейсу для пожилых пользователей
- Перевод на другие языки

## Как это сделать

1. Форкните нужный репозиторий
2. Создайте ветку: `git checkout -b fix/kratkoe-opisanie`
3. Внесите правки
4. Откройте Pull Request с описанием: что, зачем, откуда источник (если меняется медицинский контент)
5. Дождитесь review

## Что важно

- Инструмент работает **офлайн** — не добавляйте сетевые запросы
- Инструмент собирается **в один файл** — не разбивайте на модули
- **Ноль зависимостей** — никаких CDN, npm, внешних скриптов
- **Медицинский контекст** — все утверждения должны иметь источник (клинические рекомендации, приказы, методички)

## Что не принимается

- Реклама и ссылки на сторонние сервисы
- Сбор данных пользователей
- Платные интеграции
- Изменения, нарушающие принципы экосистемы
