# Политика безопасности

## Принципы

Все артефакты экосистемы работают **офлайн**, собираются в **один HTML-файл**, не используют внешних зависимостей и не собирают данные.

- **Offline-first** — работает без интернета
- **Zero dependencies** — ни библиотек, ни CDN
- **No tracking** — ноль телеметрии, cookies, аналитики
- **Strict CSP** — `connect-src 'none'`, `default-src 'none'`
- **Local-only** — данные не покидают устройство

## Что мы НЕ делаем

- Не отправляем данные на серверы
- Не создаём аккаунты и не запрашиваем email
- Не используем сторонние CDN
- Не устанавливаем сторонние зависимости
- Не используем `eval()` и `new Function()`

Исправления получает только последняя версия каждого артефакта. Устаревшие версии не обновляются, но остаются доступны в истории релизов.
